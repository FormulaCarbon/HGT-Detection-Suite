# HGT Detection Suite
A Gene-Flow Network Reconstruction Pipeline for large-scale analysis based on the framework developed by [Azad & Sengupta](https://doi.org/10.1098/rsob.220169).

## Usage

### Setup
It is recommended to use the [uv](https://docs.astral.sh/uv/) package manager. All packages can be installed by running:

```sh
uv ...
```

Or, if using `pip`:

```sh
pip install -r requirements.txt
```

Additionally, this program needs NCBI's *datasets* command-line tool, which can be installed [here](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/command-line-tools/download-and-install/).

You will also need a `.env` file. A template `.env.template` is provided to fill out, or can be configured using the tool:
```sh
python3 ...
python3 ...
python3 ...
```
